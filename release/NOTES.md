# ShortsAI v0.11.1 테스트 빌드 (예측 모델)

파일: `shortsai-v0.11.1-debug.apk` · v0.10.1·v0.11.0 위에 그대로 업데이트됩니다 (같은 디버그 키).
자세한 설계: `docs/risk-model/README.md`

## 바뀐 것

- **그 순간의 위험도로 개입:** 쇼츠·릴스를 열 때마다 AI가 "이번에 목표의 절반 이상 이어 볼 확률"을 계산해요 (지금 시각, 오늘 본 시간, 닫은 지 몇 분, 직전 시청, 이유 등 10가지).
  - 그 사람의 최근 2주 열기 중 **가장 위험한 5%** 수준이면 "몇 분 볼래요?"가 **3분만** 나와요. "조금 더 볼래요"는 그대로 있고 매번 3분씩이에요. 목표를 넘긴 뒤 "3분만 더"는 10초를 기다려요.
  - **상위 15%** 수준이면 3분에 "3분 · 추천" 표시만 붙어요.
  - 처음 50번 열기 전에는 고정 기준(10%·20%)을 써요.
- **이유를 알려 주는 한 줄:** 시트 맨 위에 "AI · 방금 닫았다가 다시 열었어요. 3분씩 끊어서 볼게요" 같은 문장이 나와요 (오늘 많이 봄 / 다시 엶 / 직전에 길게 봄 / 평소 길게 보던 때 / 그 밖).
- **예전 위험 시간대 제한은 없어졌어요:** "AI · ○시쯤은 평소 오래 보던 시간이라 조금 짧게 잡았어요"와 시간대 3분 제한·연장 1번 제한이 빠졌어요. 위험 시간 10분 전 알림과 "남겨 둘까요?"는 그대로예요.
- **설정 → AI 패널:** 설명 문장이 바뀌고, "길어지기 쉬운 때: 쇼츠를 연 N번의 기록을 보고 배우는 중이에요" 줄이 생겼어요.
- **목표를 지키는 중이면 약하게 (v0.11.1):** 최근 7일 동안 하루도 빠짐없이 목표 안에서 끝냈다면, 위험 높음이어도 3분만 나오지 않고 "3분 · 추천"만 붙어요. 보통이면 아무것도 안 해요. 하루라도 넘기면 다음 날부터 원래대로예요.
- 폰에서 학습: 열기가 끝나면(다음 열기, 또는 30분 동안 안 봄) 정답을 매겨 가중치를 조금씩 고쳐요. 3분 제한이 걸린 열기에서는 배우지 않아요.

위험도는 화면에 숫자로 나오지 않아요. 확인하려면: `adb logcat -s ShortsAIGuard` → `위험도: high 35% (full)` 같은 줄.

# ShortsAI v0.9.2 테스트 빌드 (공부 카드 강화)

파일: `shortsai-v0.9.2-debug.apk` · v0.9.1 위에 그대로 업데이트됩니다.

## 바뀐 것

- **공부 모드 (설정 → 내 공부 카드):** 켜면 쇼츠를 열 때 다른 활동 대신 공부 카드 문제가 나와요. 나올 카드가 없으면(카드 0장, 또는 모두 쉬는 중) 평소 활동으로 넘어가요.
- **간격 복습:** 틀린 문제는 1시간 뒤, 맞힌 문제는 1번 → 하루, 2번 연속 → 3일, 3번 이상 → 7일 뒤에 다시 나와요. 같은 문제가 연달아 나오지 않아요.
- **가져올 때 자동 검사:** 빈 보기, "보기1"·"..." 같은 보기, 겹치는 보기는 건너뛰고, 이미 있는 문제는 넣지 않아요. 해설이 다른 보기를 가리키면 "해설이 정답과 달라 보여요"로 표시해요.
- **방금 가져온 문제 목록:** 가져온 직후 확인하고 바로 지울 수 있어요.
- **"이 문제 이상해요":** 쇼츠 위 문제 카드(잠금 화면 포함) 아래에 있어요. 누르면 바로 빠지고 다시 안 나와요.
- **질문 문장:** PDF 첨부, 범위 적기, 개념 문제 위주, 다 만든 뒤 스스로 확인하기를 요청해요.
- **설명 추가:** 공부 카드가 어떻게 나오는지, 어떤 자료가 좋은지 설명. 공부 모드에서 카드가 30장보다 적으면 안내.
- **"관심 주제" 칸 삭제** (기사 카드 보류).

# ShortsAI v0.9.1 테스트 빌드 (AI 학습 개선)

파일: `shortsai-v0.9.1-debug.apk` · v0.9.0 위에 그대로 업데이트됩니다. 화면 문구는 바뀌지 않았습니다.

## 바뀐 것 (방식·문구를 고르는 계산만)

- **칸 사이 공유:** 기록이 적은 칸은 비슷한 칸(같은 시간대의 평일/주말, 다른 시간대, 다른 강도 순)에서 잘 맞았던 방식을 참고해 시작합니다. 빌려 오는 양은 기록 4개 정도라, 그 칸 기록이 쌓이면 자기 기록을 따릅니다.
- **최근 가중치:** 1주 전 기록은 절반, 2주 전은 4분의 1 무게. 생활이 바뀌면 며칠 안에 따라갑니다.
- **세밀한 보상:** 개입 뒤 30분 동안 실제로 더 본 시간으로 점수를 매깁니다 (바로 나감 1, 3분 약속 지킴 0.8, 15분 넘게 봄 0).
- **평일/주말 구분:** 칸이 16개(강도 2 × 시간대 4 × 평일/주말)로 나뉩니다. 빈 주말 칸은 평일 같은 시간대에서 가장 많이 빌려 옵니다.
- **질림 반영:** 방금 나온 방식·문구는 잠깐 덜 고릅니다 (6시간마다 절반씩 회복).
- 기록의 정책 버전이 `ai-2`로 남아, 업데이트 전(`ai-1`)과 비교할 수 있습니다.
- 강도 단계, 위험 시간, 엄격 모드, 잠금 규칙은 그대로입니다.

# ShortsAI v0.9.0 테스트 빌드 (AI 개인화)

파일: `shortsai-v0.9.0-debug.apk` · v0.8.2 위에 그대로 업데이트됩니다.

## 새로 들어간 AI 기능 (모두 폰 안에서 계산, 서버·비용 없음)

- **방식·문구 고르기 (밴딧):** 강도 × 시간대(아침·낮·저녁·밤)별로, 지난 30일 동안 어떤 방식과 문구 뒤에 스스로 멈췄는지 배워서 잘 맞는 쪽을 더 자주 보여 줍니다 (톰슨 샘플링). 처음엔 골고루 보여 줍니다.
- **평소 오래 보는 시간 찾기:** 지난 2주(기록 5일 이상) 중 시간대별 평균 시청이 많은 시간을 찾습니다.
  - 그 시간에는 약속 최대 3분, 연장 1번까지, "3분만 더" 대기 10초. 시트 위에 이유 한 줄을 보여 줍니다.
  - 그 시간 10분 전에 알림: [1시간 잠그기] / [괜찮아요]
  - 그 시간 전(낮)에 열면 "3분 · 추천"과 함께 예산을 남겨 두자고 제안합니다.
- **주간 목표 제안 (홈):** 지난주 5일 이상 목표를 지켰으면 2~5분 줄이자고 제안합니다. 최종 목표에 닿으면 유지 단계로 알립니다. 못 지킨 주에는 제안하지 않습니다.
- **피드백:** 나갈 때 칭찬 화면에서 5번에 1번 "도움이 됐나요?"를 묻습니다. "아니에요"는 학습 보상을 절반으로 줄입니다.
- **설정 → AI 개인화:** 켜기/끄기 (끄면 규칙대로, AI 전후 비교용), **엄격 모드** (연장과 "3분만 더" 없음), **AI가 배운 것** (평소 오래 보는 시간, 시간대별로 잘 맞은 방식)
- 강도 단계(목표의 50%·100%)와 잠금은 그대로 규칙과 사용자 선택입니다. AI가 강제로 잠그지 않습니다.

## 바뀐 점 (v0.8.0 테스트 피드백 반영)

- **약속 이어가기:** 약속한 시간이 남은 채 나갔다가 10분 안에 돌아오면 시트 없이 이어서 봅니다 ("약속한 3분 중 2분 남았어요"). 10분이 지나면 새로 묻습니다.
- **보는 중 단계가 올라가면:** 약속 시간이 끝났을 때 중간 단계에 들어섰으면 그 단계의 활동(호흡·카드 등)을 먼저 거칩니다.
- **"3분만 더":** 누를 때마다 오늘 몇 번째인지와 함께 문구가 바뀌는 화면을 한 번 거칩니다. [여기서 그만할래요]가 크게, [그래도 3분 볼래요]는 3초 뒤에 눌립니다.
- **호흡:** 누르지 않아도 됩니다. "들이마셔요 / 참아요 / 내쉬어요"를 따라 하면 됩니다.
- **잠금 뒤 질문:** "오늘은 끝" 뒤에는 묻지 않습니다. 시간 잠금이 끝나고 3시간 안에 처음 열 때만 "30분 잘 쉬었어요. 그동안 뭐 했어요?"를 묻습니다.
- **잠금 화면:** 제목이 "쇼츠 쉬는 중"으로 바뀌고, 오늘 쉰 시간을 보여 줍니다. 공부 카드가 있으면 문제 1개가 나옵니다.
- **쉰 시간과 연속 기록:** 홈과 리포트에 "쉰 시간", "잠금 연속"이 나옵니다.
- **문구 전체 교체 (확인받은 문구):** 시간 체감(어제와 비교, 평균과 비교, 목표, 잠, 누적, 미래의 나 등), 약속 끝, 강함 단계, 칭찬, 잠금 문구
- **잠과 비교:** 밤 10시~새벽 4시에 "지금 자면 6시간 20분 잘 수 있어요 (7:10 알람 기준)". 12시간 안에 울리는 알람이 있으면 그 시각을 쓰고, 없으면 설정의 **일어나는 시각**을 씁니다.
- **공부 카드:** ChatGPT·Gemini용 질문 문장이 해설(explanation)도 달라고 합니다. 문제를 풀면 해설이 나옵니다. 둥근 따옴표, 끝의 쉼표, "1번" 같은 정답 표기도 읽습니다. 직접 만들 때도 해설을 적을 수 있습니다.
- **작은 창(PIP):** 쇼츠를 작은 창으로 계속 보면 시청 중으로 봅니다. 약속 시간이 끝나면 화면 아래에서 시트가 뜨고, 나가기를 고르면 "작은 창의 X를 눌러 닫아 주세요"를 안내합니다. 닫으면 소리가 돌아오고, 1분 넘게 열려 있으면 다시 묻습니다. 화면에 떠 있는 YouTube 작은 창만 확인하고 다른 앱 이름은 기록하지 않습니다.

## 테스트 목록

빨리 보려면 **하루 목표를 2분**으로 바꿉니다.

| # | 해볼 것 | 기대 결과 | 결과 |
|---|---|---|---|
| 1 | 진입 → "3분" → 바로 BACK → 곧바로 다시 진입 | 시트 없이 이어서 재생, "약속한 3분 중 …분 남았어요" 안내 | |
| 2 | 위에서 나간 뒤 10분 넘게 있다가 진입 | 새로 시트가 뜸 | |
| 3 | 가벼움 단계에서 3분 약속 → 그대로 보다가 목표 절반을 넘김 | 약속 시간이 끝나면 호흡·카드 등 활동 → "정한 3분이 됐어요" | |
| 4 | 목표를 넘긴 뒤 "3분만 더" 여러 번 | 회차마다 문구가 바뀌고 [그래도 3분 볼래요]는 3초 뒤 활성 | |
| 5 | 호흡 따라 하기 | 누르지 않아도 문구와 원이 바뀌고 30초 뒤 다음으로 | |
| 6 | 10분 잠금 → 잠금 중 진입 | "쇼츠 쉬는 중", 남은 시간, 쉰 시간, (카드가 있으면) 문제 1개 | |
| 7 | 10분 잠금이 끝난 뒤 진입 | "10분 잘 쉬었어요. 그동안 뭐 했어요?" | |
| 8 | "오늘은 끝" 뒤 다음 날 아침 진입 | 잠금 뒤 질문이 **안** 나옴 | |
| 9 | 공부 카드: 질문 문장 복사 → ChatGPT → 결과 붙여넣기 | 가져와지고, 문제를 풀면 해설이 보임 | |
| 10 | 밤 10시 이후 진입 (알람이 있을 때 / 없을 때) | "지금 자면 …" 문구와 "(7:10 알람 기준)" 같은 기준 | |
| 11 | 쇼츠를 보다가 홈 버튼으로 **작은 창(PIP)** | 시간이 계속 쌓이고, 약속 시간이 끝나면 시트가 뜸 | |
| 12 | PIP에서 시트 → 나가기 | "작은 창의 X를 눌러 닫아 주세요" → X로 닫으면 소리 돌아옴 | |
| 13 | 홈·리포트 | 쉰 시간, 잠금 연속, 새 문구 | |
| 14 | 롱폼 영상을 PIP로 보기 | 개입 없음 | |

11, 12, 14번(PIP)은 폰마다 화면 정보가 달라 실제로 확인이 필요합니다. 결과가 이상하면 폰을 USB나 무선 디버깅으로 연결해 로그를 함께 봅니다.

## 알려진 점

- 다른 앱의 작은 창(PIP)은 ShortsAI가 직접 닫을 수 없어 닫기를 안내만 합니다.
- 잠과 비교는 12시간 안에 울리는 알람을 기상 시각으로 봅니다. 낮잠 알람이면 기준이 틀릴 수 있어 문구 끝에 기준을 같이 보여 줍니다.
