# ShortsAI 프로젝트 요약 (아이디어 논의용)

> 이 문서는 다른 AI 채팅에 붙여 넣고 아이디어를 논의하기 위한 요약이다.
> 코드는 Claude Code에서 작성 중이며, 여기서 나온 아이디어는 다시 Claude Code에 가져가 구현한다.

## 1. 프로젝트 개요
- **3인 캡스톤 프로젝트.** YouTube 쇼츠 과다 시청을 줄이는 안드로이드 앱
- **원래 계획:** "Focus on (한박자)". 팀원 저장소를 바탕으로, 별도 앱으로 다시 만들었다.
- **앱:** 이름 ShortsAI, 패키지 `app.focuson.shorts`
- **현재 버전:** v0.9.0 (AI 개인화 포함). v0.8.0까지는 실제 폰(삼성 갤럭시)에서 확인했다.
- **배포:** GitHub Releases에 디버그 APK를 올린다.
- **핵심 아이디어:** 쇼츠를 열면 바로 막지 않는다. 목표 대비 사용량에 따라 **단계별로 개입**하고, 사용자가 **스스로 멈추게** 돕는다.

## 2. 기술 구조
- **하이브리드 앱:** Next.js 16 + React 19 + TypeScript(화면)를 Capacitor 8로 감싸고, 안드로이드 네이티브(Java)를 붙였다.
- **네이티브:** 접근성 서비스가 쇼츠를 감지한다. 화면 요소 ID만 보고 글자는 읽지 않는다. 오버레이로 개입 화면을 띄우고, AudioFocus로 영상을 멈춘다.
- **저장:** 폰 안 SQLite. 외부 서버 없음, API 키 없음, 비용 0원
- **데이터 흐름:** 네이티브 기록 큐 → 웹이 1.5초마다 동기화 → SQLite. 웹이 정책(목표, 단계, 방식)을 만들어 네이티브에 전달한다.
- **안드로이드만 지원:** iOS는 다른 앱 화면을 볼 수 없어서 쇼츠와 일반 영상을 구분할 수 없다.

## 3. 기능 (v0.8.2, AI 이전)
- **단계 (목표 대비 오늘 사용량):** 약함 <50%, 중간 <100%, 강함 ≥100%
- **진입 시 개입:** 영상과 소리를 멈추고 아래쪽 시트를 띄운다. 6가지 방식을 차례로 번갈아 쓴다.
  - 5초 숨 고르기
  - 시간 체감 문구: 어제 같은 시간과 비교, 주 평균과 비교, 목표 대비, 알람 기준 수면 시간
  - 호흡 따라 하기
  - 대체 행동: 물, 스트레칭, 걷기, 눈 쉬기
  - 성찰 질문 (객관식)
  - 공부 카드 (퀴즈와 해설)
- **약속 "몇 분 볼래요?":** 3, 5, 10분 중 고른다.
  - 시간이 되면 다시 멈추고 묻는다.
  - 연장할 때마다 선택지가 줄어든다 (10 → 5 → 3분).
  - 10분 안에 돌아오면 남은 약속이 이어진다.
- **강함 단계:**
  - "오늘은 끝": 다음 날 06시까지 잠근다.
  - 잠그기: 10, 20, 30, 60분
  - "3분만 더": 3초 기다려야 누를 수 있다. 횟수 제한은 없다.
- **잠금:** "쇼츠 쉬는 중" 화면에 남은 시간, 오늘 쉰 시간, 공부 카드를 보여 준다.
  - 잠금이 끝나면 "그동안 뭐 했어요?"를 한 번 묻는다.
  - 스스로 멈추거나 잠그면 칭찬 문구가 나온다.
- **작은 창(PIP):** 감지한다.
  - 나가면 큰 화면 펼치기를 한 번만 시도한다.
  - 창이 남아 있으면 닫기를 안내하고 계속 본 시간을 기록한다.
  - 60초 뒤 한 번 더 묻는다. 무한 반복은 없다.
- **앱 화면:**
  - 홈: 게이지, 시간대별 막대, 한 줄 요약, 쉰 시간, 연속 잠금
  - 통계와 리포트
  - 설정: 목표, 최종 목표, 하루 끝 시각, 기상 시각, 관심 주제, 카드 관리
- **공부 카드:** 외부 AI에서 만든 퀴즈를 붙여 넣어 가져온다.
- **개입 끄기:** 3초 기다려야 끌 수 있다.
- **매일 리포트 알림**

## 4. 기능 (v0.9.0, AI 개인화, 전부 폰 안에서 계산)
- **밴딧 (톰슨 샘플링):** 단계와 시간대별로 잘 먹힌 개입 방식과 문구를 더 자주 고른다.
  - 보상: 멈춤 1, 30분 안에 다시 오면 0.5, "도움 안 됨"이면 절반
  - 최근 30일 기록을 쓴다.
- **위험 시간:** 기록이 5일 이상 쌓이면 찾는다. 기준은 지난 14일 중 그 시간 평균이 5분 이상이고, 다른 시간대 평균의 1.5배 이상인 시간이며, 최대 3개다.
  - 위험 시간에는 약속 최대 3분, 연장 1번, "3분만 더" 대기 10초
  - "평소 오래 보던 시간이라 조금 짧게 잡았어요" 안내가 뜬다.
- **위험 시간 10분 전 알림:** [1시간 잠그기] / [괜찮아요] 버튼
- **남겨 두기 추천:** 위험 시간 전에는 "지금은 3분만 쓰고 남겨 둘까요?"
- **주간 목표 조정 제안:** 지난주 5일 이상 목표를 지키면 2~5분 줄이자고 제안한다. 최종 목표와 5분 아래로는 내리지 않는다.
- **피드백:** 칭찬 화면 5번 중 1번 "도움이 됐나요?"를 묻는다.
- **설정:** AI 켜기/끄기 (전후 비교 실험용), 엄격 모드 (연장과 "3분만 더"를 숨김)
- **AI 패널:** AI가 배운 것을 그대로 보여 준다 (설명 가능성).

## 5. 지켜 온 원칙 (아이디어도 이 안에서)
- **강제하지 않는다.** 선택지를 줄이고 대기를 늘릴 뿐, 사용자의 선택은 남긴다. 횟수 제한이나 "깨끗한 5분" 같은 압박은 뺐다.
- **무한 반복은 절대 안 된다.** 같은 안내를 계속 띄우는 구조는 금지
- **돈이 드는 것은 곤란하다.** 유료 API나 서버를 쓰지 않는다. 무료 계정으로 되는 것만 고려한다.
- **개인정보:** 화면 글자, 메시지, 계정 정보는 읽지 않는다. 기록은 폰 밖으로 내보내지 않는다.
- **의료 효과를 주장하지 않는다.** "치료", "진단" 같은 표현을 쓰지 않는다.
- **성찰은 객관식으로** (주관식 입력 부담을 없앤다)
- **화면 문구는 상황별 표로 먼저 확인받고 바꾼다.**

## 6. 알려진 한계와 미확인 부분
- 다른 앱의 작은 창은 앱이 직접 닫을 수 없다. 안내만 할 수 있다.
- v0.8.1~v0.9.0 기능은 아직 폰에서 확인하지 않았다. 특히 작은 창 펼치기와 알림 버튼으로 잠그기가 그렇다.
- AI는 기록이 쌓여야(5일 이상) 효과가 보인다. 처음에는 여러 방식을 골고루 시도한다.
- 위험 시간 알림 문구는 "11시부터"인데, 실제로는 누른 순간부터 1시간 잠긴다. 고칠지 결정이 필요하다.

## 7. 앞으로 할 일 / 논의하고 싶은 것
- 관심 주제 기사 카드: 무료 Cloudflare와 Gemini 계정이 필요하다. 할지 말지 정해야 한다.
- 마지막 단계: 각 기능을 **행동과학 이론과 논문**에 연결한 근거 문서 (출처 포함)
  - 예상 연결: 사전 약속(precommitment), 마찰(friction), 넛지, 이행 의도, 시간 할인, 강화학습 밴딧
- 교수님 발표 준비 (기능, 선택 이유, 기술 구조)
- **새 아이디어:** 위 원칙 안에서, 쇼츠를 스스로 멈추게 돕는 기능이나 개선점
