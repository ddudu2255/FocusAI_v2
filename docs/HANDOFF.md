- **지금은 팀원 Supabase를 팀원 방식 그대로** (앱이 공개 키로 바로 올림). Spring Boot는 시간이 남으면 그 앞에 끼운다 (DB·표는 그대로, 앱의 `lib/sync-config.ts` 주소만 바꿈). 사용자 결정 2026-10-26.

| `GuardOverlay` | 화면 위 시트 (`TYPE_ACCESSIBILITY_OVERLAY` + `FLAG_NOT_FOCUSABLE`). 코드로 만든 어두운 시트. |
| `GuardState` | SharedPreferences. 세션·개입·잠금 시도를 대기열에 쌓아 두고, 웹이 SQLite에 저장한 뒤 ack 하면 지운다. 그 밖에 날짜별 사용 초, `blocked_until`, 기준 시간. |
| `GuardNotifier` | 잠금 중 상태바 카운트다운. |
| `GuardTime` | 자정 분할, Level 계산. |
| `GuardCopy` | 이유 6개와 대체행동 문구. |
| `GuardPlugin` | 웹 ↔ 네이티브 연결: `getStatus`, `setBlocker`, `sync`, `ack`, `finish`, `startBlock`, `resetRecords`, `openSettings`. JS 이름은 `HanbakjaGuard`. |

### 웹 (`lib/`, `components/`)

| 파일 | 역할 |
|---|---|
| `lib/db.ts` | SQLite 표: `sessions`, `interventions`, `lock_attempts`, `settings`(키-값). 첫 실행 때 localStorage 기록을 옮긴다. |
| `lib/persist.ts` | 안드로이드는 SQLite, 브라우저는 localStorage. |
| `lib/notify.ts` | 매일 리포트 알림 (`@capacitor/local-notifications`). |
| `components/store.tsx` | 앱 상태. 모든 변경은 `mutate`로 상태와 저장소를 함께 바꾼다. |
| `components/guard-bridge.tsx` | 1.5초마다 서비스와 동기화: 기준 시간 전달 → 기록 받기 → SQLite 저장 → ack. |
| `lib/logic.ts` | 통계, 자정 분할, 네이티브 기록 변환, 30분 내 재진입 판정. |

현재 Level은 오늘 누적 시간 기준이다 (10분 미만 1, 20분 미만 2, 그 이상 3). 개입 기록에는 시각, 요일, 대상, 개입 종류, 30분 내 재진입, feedback 칸이 있다.

## 4. 폰 테스트에서 나온 문제 (v0.7.0, 갤럭시 SM-S936N)

1. **영상이 안 멈춤:** 시트가 떠도 영상과 소리가 계속 나온다. 미디어 일시정지 키가 YouTube 쇼츠에 먹히지 않는다.
2. **시트 뒤 영상이 잘 보인다.**
3. **보는 중에 단계가 안 바뀐다:** 시청을 고른 뒤 계속 보면 기준 시간을 넘어도 개입이 없다. 단계는 진입할 때만 정해진다.
4. **Level 3 반복:** 잠금이 끝나도 계속 Level 3이라 "잠금 → 또 잠금 선택"이 반복된다.
5. **Level 1과 2의 차이가 작다.**
6. **Level 3 경고 문구가 어색하다** ("오늘은 이미 충분히 봤습니다").
7. **개입 스위치를 꺼도 차단이 유지된다:** 의도된 동작이다. 유지하기로 했고, 대신 끄기 경고창에서 안내한다.
8. **설치 후 접근성 "액세스 거부됨":** 안드로이드 제한된 설정 때문이다. 앱 정보 → ⋮ → 제한된 설정 허용으로 해결.

## 5. 다음 버전 v0.8.0 명세 (AI 제외 완성본)

### 5.1 개입 엔진: 강도 3단계 × 방식 묶음

기존의 Level 1·2·3 순서를 아래 구조로 바꾼다.

**강도는 규칙으로 정한다** (오늘 목표 사용 비율 기준)

| 강도 | 오늘 목표 사용 | 바닥선 |
|---|---|---|
| 가벼움 | 0~50% | 이유 고르기 + 시청 약속 |
| 중간 | 50~100% | "멈추는 활동"을 하나 거쳐야 볼 수 있다 |
| 강함 | 100% 초과 | 마무리 선택 (5.3) |

**방식은 강도별 후보 중에서 고른다** (v0.8.0에서는 **번갈아** 보여준다. 고르게 섞어서 기록을 쌓는다)

| 방식 | 쓸 수 있는 강도 |
|---|---|
| 5초 숨 고르기 | 가벼움, 중간 |
| 시간 바꿔 말하기 (5.5) | 가벼움, 중간 |
| 호흡 따라 하기: 원을 따라 누르고 떼기 3번 (참여 확인됨) | 중간 |
| 대체행동 (물·스트레칭·눈 쉬기 등, 30초 뒤 "했어요" = 스스로 답함) | 중간 |
| 내 공부 카드 (5.7) | 중간 |
| 관심 주제 기사 카드 (자리만 만들어 둔다. 내용 생성은 AI 단계) | 중간 |
| 성찰 질문 (**객관식만**. 예: "지금 보면 뭐가 남을까요?" → [기분 전환] [아무것도] [할 일 미루는 중] [잘 모르겠어요]) | 중간, 강함 |
| 마무리 선택 | 강함 (항상) |

- **걸음 수 센서는 쓰지 않는다** (권한 문제와 갤럭시의 지연 보고 때문).
- 이유 6개 고르기는 유지한다.

### 5.2 하루 목표와 시청 약속 (예산 방식)

**설정**
- "Level 2/3 기준 시간"을 **하루 목표 시간**(예산)으로 바꾼다.
- **최종 목표** 칸을 추가한다. AI 단계에서 목표를 줄여 가는 데 쓴다.

**Level 계산**
- 오늘 누적 기준이다. 쉬어도 내려가지 않는다.
- "최근 시간 기준으로 쉬면 내려가는" 방식은 쓰지 않기로 했다.

**시청 약속**
- 시트에서 이유를 고른 다음, 같은 시트 안에서 **"몇 분 볼래요?"** 3분 / 5분 / 10분 중 하나를 고른다.
- 남은 예산보다 큰 선택지는 숨긴다.
- 한 번 약속은 최대 10분이다.
- 바로 이어서 연장하면 선택지가 10 → 5 → 3분으로 줄어든다 (몰아보기 마찰).
- **약속 시간이 끝나면** 영상을 멈추고 "정한 N분이 됐어요"를 띄운다.
  - **나가기:** 칭찬을 보여주고 "스스로 멈춘 횟수"가 1 올라간다.
  - **더 보기:** 남은 예산 안에서 새로 약속하고, 연장으로 기록한다.
- 이걸로 "보는 중에 단계가 안 바뀌는" 문제(4장 3번)도 해결된다. 약속이 끝나면 그 시점의 강도로 다시 판단한다.

### 5.3 강함 단계 (목표 초과): 마무리 선택

- **제목:** "오늘은 여기까지 해볼까요?"
- **본문:** "오늘 벌써 {N}분 봤어요. 한 개만 더 보려다 30분이 지나기 쉬워요. 지금 멈추거나, 잠시 쇼츠를 잠가 둘 수 있어요."

| 선택지 | 내용 |
|---|---|
| **오늘은 끝** (가장 크게) | 내일 아침까지 잠근다. 풀리는 시각 기본값은 **오전 6시**이고 설정에서 바꿀 수 있다. 리포트에 "스스로 마무리"로 표시하고 칭찬한다 |
| 10·20·30·60분 잠금 | 지금 있는 기능 그대로 |
| 3분만 더 (작게) | 3초를 기다려야 누를 수 있다. 3분 뒤 자동으로 멈춘다. 리포트에 "목표 초과"로 표시한다 |

- **잠금이 끝난 뒤 처음 진입할 때** "잠금 동안 뭐 했어요?"를 물어본다: [쉬었어요] [공부·일] [그냥 기다림] (객관식)
- 지금처럼 YouTube를 닫고 웹 화면으로 가는 대신, **이것도 YouTube 위 시트로** 바꿀지는 구현할 때 판단한다. 시트가 일관성 면에서 낫다.

### 5.4 화면 위 시트 개선

**영상 멈추기** (아래 순서로 적용한다)
1. 시트가 뜰 때 오디오 포커스를 요청한다 (`AUDIOFOCUS_GAIN_TRANSIENT`). YouTube가 멈추고, 포커스를 풀면 다시 재생하는지 기대한다.
2. 보조: 시트가 떠 있는 동안 음악 볼륨을 음소거하고, 닫으면 원래대로 되돌린다.
3. 1·2로 부족하면 마지막 수단으로 화면 탭 제스처를 쓴다 (`canPerformGestures` 필요, 재생 토글 위험이 있다).

**모양**
- 멈추기가 되면 시트 높이는 **절반 그대로** 둔다. 뒤 배경만 더 어둡게 한다 (투명도 0.6 → 약 0.9).
- 단계 숫자 대신 **"오늘 목표의 64% 사용"** 게이지를 보여준다.

### 5.5 시간 체감 장치

- **시간 바꿔 말하기:** "오늘 32분 = 쇼츠 약 120개 / 걷기 3km / 책 20쪽"
  - 정해진 환산 비율로 **코드가 계산**한다.
  - 문구 종류(쇼츠 개수, 걷기, 책, 수면, 공부)는 번갈아 보여준다. AI 단계에서는 밴딧이 고른다.
- **하루 막대:** 오늘 언제 얼마나 봤는지를 시트와 홈에 막대로 보여준다.
- **남은 예산:** "오늘 남은 시간 N분"을 시트와 홈에 크게 보여준다.

### 5.6 칭찬과 리포트

- 나가기를 고르거나 약속을 지키면 그 자리에서 짧게 칭찬한다. 예: "방금 나간 건 진짜 어려운 일이에요."
- 리포트 맨 앞에 **"오늘 스스로 멈춘 횟수 N번"**을 둔다.
- 리포트에 함께 보여줄 것: 스스로 마무리 여부, 목표 초과 횟수, 연장 횟수, 잠금 중 시도.
- 리포트 문장은 **정해진 문장 틀에 숫자만 채운다.** 사용자가 쓴 글이나 AI가 만든 문장은 넣지 않는다.

### 5.7 내 공부 카드 (서버 없음)

- 앱 설정 화면에서 직접 입력한다: 문제 + 보기 4개 + 정답.
- **붙여넣기 가져오기:**
  1. 앱이 "카드 만들기용 질문 문장"을 보여준다.
  2. 사용자가 무료 ChatGPT나 Gemini에서 그 문장으로 정해진 형식(JSON)의 문제를 만든다.
  3. 결과를 앱에 붙여넣으면 카드로 저장된다.
- 중간 강도에서 문제 1개를 보여준다. 답을 고르는 것이 참여 확인이다. 정답 여부를 기록하고, 리포트에 "쇼츠 대신 푼 문제 N개"로 보여준다.
- 텍스트 입력은 앱 화면에서만 한다. 시트에서는 고르기만 한다.

### 5.8 개입 스위치 끄기 경고

- **제목:** "정말 끌까요?"
- **본문 (번갈아 사용)**
  - "오늘 쇼츠를 벌써 {N}분 봤어요. 지금 끄면 아무도 멈춰주지 않아요."
  - "끄는 건 쉬워요. 다시 켜는 건 생각보다 어려워요. 오늘 {N}분, 정말 괜찮으세요?"
- **버튼:** **"계속 켜둘게요"** (크게) / "그래도 끌래요" (작게, **3초 뒤에** 눌림)
- **차단 중이면** 한 줄 추가: "지금 걸린 차단은 남은 {M}분 동안 계속돼요." (스위치를 꺼도 차단은 유지한다)

### 5.9 그 밖에

- Instagram Reels는 지금 방식(앱 화면 이동)을 유지한다.
- iOS는 하지 않는다.

## 6. AI를 위해 v0.8.0에서 미리 만들어 둘 구조

AI를 나중에 붙일 때 **화면과 흐름은 그대로 두고, 값을 정하는 부분만 바꾸면 되도록** 만든다.

### 6.1 정책표 (Policy)

- 네이티브가 개입 순간 **이 표만 읽고** 바로 결정한다.
- 웹이 계산해서 `GuardPlugin`으로 넘겨 SharedPreferences에 저장한다.
- v0.8.0은 규칙 기반 고정값으로 채운다. AI 단계에서는 같은 형식으로 AI가 채운다.
- 들어갈 항목 예시:

| 구분 | 항목 |
|---|---|
| 강도 기준 | 목표 대비 비율 (50%, 100%) |
| 강도별 방식 후보 | 목록과 각 방식의 가중치 (v0.8.0은 균등 = 번갈아) |
| 시간대별 세부 수치 | 약속 최대 분, 연장 허용 횟수, "3분만 더" 대기 초, 강함 단계의 기본 선택 |
| 문구 후보 | 시간 바꿔 말하기 종류와 가중치 |
| 표의 정보 | 버전과 만든 시각 |

### 6.2 기록 추가 (학습 재료)

개입 한 번마다 아래를 남긴다 (`interventions` 표에 칸 추가, 또는 `intervention_steps` 표 새로 만들기).

| 항목 | 예 |
|---|---|
| 강도 | 가벼움 / 중간 / 강함 |
| 보여준 방식, 보여준 문구 종류 | 호흡, 책 환산 |
| 참여 확인 수준 | 확인됨 / 스스로 답함 / 없음 |
| 성찰 답, 잠금 뒤 돌아보기 답 | 할 일 미루는 중 |
| 약속 시간, 약속을 지켰는지 | 5분, 지킴 / 연장 횟수 |
| 카드 정보 | 카드 id, 정답 여부, 카드 평가 ([흥미로웠어요] / [별로예요]) |
| 결과 | 나가기 / 시청 / 오늘은 끝 / 잠금 / 3분만 더 |
| 정책표 버전 | 그때 적용된 정책표 |
| 기존 칸 | 30분 내 재진입, feedback |

### 6.3 콘텐츠 카드 자리

- `cards` 표를 만든다: 종류(공부 / 기사), 출처, 내용, 만든 시각, 사용 여부.
- 시트에 카드 표시 화면을 만든다.
- 관심 주제 입력 칸은 설정에 만들어 두되, 내용 생성은 AI 단계에서 한다.

## 7. AI 단계 (마지막에 넣기, **비용 0원 원칙**)

### 7.1 개인화 (폰 안에서 계산, 무료)

**방식과 문구 고르기:** 문맥이 있는 멀티암드 밴딧 (톰슨 샘플링)
- 문맥: 시간대, 요일, 목표 사용 비율
- 보상: 나가기를 골랐는지 + 30분 안에 다시 안 들어왔는지
- 처음 1~2주는 탐색하고, 이후 잘 먹히는 쪽을 점점 더 자주 보여준다.

**강도는 AI가 올리지 않는다.** 목표를 안 넘었는데 강함 단계로 올리는 건 엄격 모드나 사용자가 정한 시간대 규칙에서만 한다.

**위험 시간대 대응**
- 같은 단계 안에서 세부 수치를 조인다 (약속 3분, 연장 불가, 대기 10초, "오늘은 끝" 미리 선택)
- 밤에 효과가 좋았던 방식을 먼저 쓴다.
- **위험 시간 직전 알림:** "곧 평소 오래 보던 시간이에요. 잠가 둘까요?" → 사용자가 확정한다.
- **예산 남겨두기 제안:** "밤용으로 남겨둘까요?"
- **수면 시간 규칙 제안:** AI가 찾고 사용자가 확정한다.

**목표 줄이기 (주 1회 제안)**
- 지난주에 목표를 지킨 경우에만 줄인다 (예: 7일 중 5일 이상).
- 2~5분 단위로 줄인다. 퍼센트로 줄이면 나중에 의미 없을 만큼 작아지기 때문이다.
- 최종 목표에 닿으면 멈추고 유지 모드로 바꾼다. 바닥값도 둔다 (예: 5분).
- 실패한 주는 그대로 두거나 늘린다.
- AI가 제안하고 사람이 버튼 하나로 확정한다 (기본값 효과).

**설명과 피드백**
- 개입마다 이유 한 줄을 보여준다: "밤 11시엔 평소 연장이 많았어요."
- [도움 됐어요] [아니에요] 버튼을 둔다.

**엄격 모드**
- 사용자가 직접 켜야 한다 (율리시스 계약). 켜면 AI 값을 바꿀 수 없고, 연장과 "3분만 더"가 사라진다.

### 7.2 관심 주제 기사 카드 (무료 스택) — **보류 (2026-10-08 결정)**

> 검토 결과: 위키백과 첫 문단은 정의라 중학생 이상에게 의미가 적고, "몰랐던 사실"을 고르는 기준이 애매하며, 요약 AI는 틀릴 수 있다. 앱의 핵심 목표는 쇼츠 줄이기와 습관 개선이므로 **좋은 결과가 확실하지 않으면 넣지 않는다.** 아래 설계는 기록으로만 남긴다.

**흐름**
1. 설정에 관심 주제를 입력한다 (예: "AI").
2. 앱이 열려 있을 때 하루 한 번 요청한다.
3. 무료 서버가 Google 뉴스 RSS에서 최신 기사를 받는다.
4. **Gemini API 무료 요금제**로 3줄 요약한다.
5. 폰 SQLite에 저장하고, 개입 때 저장된 카드만 보여준다 (그 순간에는 인터넷을 쓰지 않는다).

**구성**
- 무료 서버: Cloudflare Workers 무료 요금제
- **사용자가 준비할 것:** Google AI Studio 키, Cloudflare 계정. 키는 서버 비밀값으로만 둔다.

**안전장치**
- 정해진 형식(JSON)만 받고 형식이 틀리면 버린다.
- 요약과 원문 링크만 보여준다 (저작권). 원문은 저장하지 않는다.
- 사용자당 하루 생성 개수 상한, 앱별 토큰을 둔다.
- 무료 요금제는 보낸 데이터가 서비스 개선에 쓰일 수 있다. 주제어만 보내니 부담이 적지만 그래도 알린다.
- 무료 조건은 시작할 때 공식 문서로 다시 확인한다.

**하지 않는 것:** PDF·시험 이름으로 자동 문제 만들기. 무료 한도, 정확도, 개인 자료 전송 문제로 제외했다. 공부는 5.7의 직접 입력과 붙여넣기로 한다.

**선택 사항:** 지원 기기에서는 Gemini Nano(폰 안 AI)로 요약할 수도 있다.

### 7.3 유료 API는 쓰지 않는다

- Claude API도 유료라 쓰지 않는다.
