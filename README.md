# ShortsAI

YouTube Shorts를 열면 한 박자 멈추고, 오늘 얼마나 봤는지에 따라 개입의 세기를 바꾸는 안드로이드 앱입니다. 3인 팀 캡스톤 프로젝트이고, 팀원의 hanbakja(Focus on)를 바탕으로 만든 별개 앱입니다.

흐름: **감지 → 이유 질문 → Level 1~3 개입 → 결과 기록 → 통계와 일일 리포트**. 쌓인 기록은 이후 AI 개인화(개입 방식 학습, 위험 시간대 예측)에 씁니다.

기록은 기기 안에만 남습니다. 화면의 글, 메시지, 비밀번호, 계정은 읽거나 저장하거나 보내지 않습니다. 계정, 서버, API 키는 없습니다.

- 패키지 이름: `app.focuson.shorts` (팀원 앱 `app.hanbakja.shorts`와 따로 설치됩니다)
- 대상: 안드로이드. YouTube Shorts 기준이고, Instagram Reels는 이전 방식으로 개입합니다.

## 안드로이드에 설치

APK는 GitHub Releases에서 받습니다. 파일 이름은 `shortsai-v<버전>.apk` 입니다.

1. 휴대폰 브라우저에서 Releases의 APK를 눌러 내려받습니다.
2. 알림이나 다운로드 목록에서 파일을 엽니다.
3. **출처를 알 수 없는 앱** 설치를 허용하라는 안내가 나오면, 이 브라우저에 대해 허용합니다. 설치가 끝나면 다시 꺼 두는 것이 안전합니다.
4. 안드로이드 13 이상: **설정 → 애플리케이션 → ShortsAI → 오른쪽 위 ⋮ → 제한된 설정 허용**을 먼저 누릅니다.
5. **설정 → 접근성 → 설치된 앱(또는 다운로드한 앱) → ShortsAI**를 켭니다. 앱 안의 **접근성 설정 열기** 버튼도 같은 화면으로 갑니다.
6. ShortsAI 설정 화면에서 **알림 허용 요청**을 누릅니다. 리포트 알림과 잠금 남은 시간 알림에 씁니다.
7. 팀원 앱(Focus on)도 설치되어 있다면 그 앱의 접근성은 꺼 주세요. 둘 다 켜면 개입이 두 번 뜹니다.

끄는 법: 앱의 **쇼츠·릴스 개입** 스위치를 끄거나, **설정 → 접근성 → ShortsAI**를 끄거나, 앱을 삭제합니다.

## 쓰는 법

YouTube에서 쇼츠 화면이 열리면 영상이 멈추고 소리가 꺼진 뒤, 그 위에 시트가 올라옵니다. 일반 영상, 홈 피드, 검색에서는 나오지 않습니다. 강도는 **오늘 목표**(설정, 기본 20분) 대비 사용 비율로 정합니다.

| 오늘 목표 사용 | 강도 | 개입 |
|---|---|---|
| 50% 미만 | 가벼움 | 5초 숨 고르기 또는 시간 바꿔 말하기 → 이유 → **"몇 분 볼래요?"** (3·5·10분) |
| 100% 미만 | 중간 | 호흡 따라 하기 / 대체행동 / 성찰 질문 / 내 공부 카드 등 멈추는 활동 하나 → 이유 → 몇 분 |
| 100% 이상 | 강함 | "오늘은 여기까지 해볼까요?" → **오늘은 끝**(다음 날 6시까지) / 10·20·30·60분 잠금 / 3분만 더 |

- 같은 강도 안에서는 방식을 번갈아 보여 줍니다 (같은 화면에 익숙해지지 않게, 그리고 어떤 방식이 효과적인지 기록하려고).
- **정한 시간이 되면** 다시 멈추고 "약속 지키고 나가기" 또는 "조금 더 볼래요"(연장할수록 10 → 5 → 3분)를 고릅니다.
- **나가기**는 시트 맨 아래 같은 자리에 있습니다. 누르면 칭찬 한 줄 뒤 뒤로 가고, 0.8초 뒤에도 쇼츠면 홈으로 갑니다.
- **잠금 중**에 쇼츠를 열면 남은 시간이 보이는 잠금 시트가 뜨고 몇 초 뒤 자동으로 나갑니다. 잠금이 끝난 뒤 처음 열면 "잠금 동안 뭐 했어요?"를 묻습니다.
- **내 공부 카드**: 설정에서 직접 만들거나, ChatGPT·Gemini 무료 채팅으로 만든 결과를 붙여넣습니다. 중간 강도에서 가끔 문제 하나로 나옵니다.
- 개입 스위치를 끄려면 한 번 더 확인합니다. 꺼도 쇼츠 사용 시간은 기록하고, 걸린 잠금은 유지됩니다.
- 매일 설정한 시각에 "오늘 리포트가 준비됐어요" 알림이 옵니다. 리포트 맨 앞에는 "스스로 멈춘 횟수"가 나옵니다.
- 홈의 **쇼츠 열기**는 연습용 피드입니다.
- Instagram Reels는 ShortsAI 화면으로 넘어가 개입합니다.

## 기록하는 것

모두 기기 안의 SQLite 데이터베이스에 저장합니다.

| 표 | 내용 |
|---|---|
| `sessions` | 쇼츠를 본 시작·종료 시각, 대상 앱, 시간. 자정을 넘긴 세션은 통계에서 날짜별로 나눕니다. |
| `interventions` | 시각, 요일, 강도, 단계, 보여 준 방식과 문구, 참여 확인, 고른 이유, 성찰 답, 약속 시간, 카드 정답, 결과(나가기·약속 지킴·연장·오늘은 끝·잠금·3분만 더), 30분 안에 다시 열었는지, 정책표 버전 |
| `lock_attempts` | 차단 중에 쇼츠를 연 시각과 남은 잠금 시간 |
| `cards` | 내 공부 카드 (문제, 보기, 정답, 나온 횟수, 맞힌 횟수) |
| `settings` | 하루 목표, 최종 목표, 알림 시각, "오늘은 끝" 해제 시각, 관심 주제, 차단 상태 |

이전 버전(localStorage)에 기록이 있으면 처음 실행할 때 옮깁니다.

## 개발

필요한 것: Node 20 이상, JDK 21, Android SDK (`android/local.properties`에 `sdk.dir`).

```bash
npm install
npm test            # 웹 로직 테스트
npm run dev         # 브라우저에서 화면 확인 (http://localhost:47231)
npm run apk:debug   # 테스트용 APK → release/shortsai-v<버전>-debug.apk
npm run apk         # 서명된 APK → release/shortsai-v<버전>.apk
```

네이티브 단위 테스트: `cd android && ./gradlew testDebugUnitTest`

디버그 APK의 로그: `adb logcat -s ShortsAIGuard` (화면 ID와 상태만 남습니다)

### 버전

`package.json`의 `version` 하나만 바꿉니다. APK의 versionName과 versionCode(예: 0.7.0 → 700), 설정 화면의 버전 표시가 모두 이 값을 씁니다.

### 서명 키 (release APK)

키스토어는 직접 만들고, 파일과 비밀번호는 git에 넣지 않습니다.

```bash
keytool -genkeypair -v -keystore android/shortsai-release.jks -alias shortsai -keyalg RSA -keysize 2048 -validity 10000
```

`android/keystore.properties`:

```
storeFile=shortsai-release.jks
storePassword=<키스토어 비밀번호>
keyAlias=shortsai
keyPassword=<키 비밀번호>
```

`.jks` 파일과 비밀번호는 따로 백업하세요. 잃어버리면 같은 앱 위에 업데이트 설치가 안 되고, 지운 뒤 새로 설치해야 합니다.

## 구조

- 웹 화면: Next.js(TypeScript) 정적 빌드를 Capacitor로 감쌉니다. 홈, 통계, 리포트, 설정, Level 3 화면.
- 네이티브(`android/app/src/main/java/app/focuson/shorts/`):
  - `ShortsGuardService`: 접근성 서비스. 감지, Level 판단, 오버레이, 나가기, 세션 기록
  - `GuardScreens`: 쇼츠 판별 규칙 (쇼츠 ID가 보이고 롱폼 ID는 안 보일 때만)
  - `ShortsSessionTracker`: 진입·종료 상태 기계
  - `GuardPolicy`: 정책표 (강도 기준, 강도별 방식, 약속 시간, 연장 사다리). 웹이 만들어 넘기고, AI 단계에서는 AI가 채운다
  - `GuardFlow`: 시트 안의 단계 순서 (방식 → 이유 → 약속, 약속 끝, 강함, 잠금)
  - `GuardOverlay`: YouTube 위 바텀시트 틀
  - `GuardState`: 기록 대기열, 차단, 정책표와 카드, 번갈아 보여 주기 순번 (기록은 웹이 가져가 SQLite에 저장한 뒤 지움)
  - `GuardPlugin`: 웹 ↔ 네이티브 연결
- 작업 지시서와 진행 상황: [docs/WORK_ORDER.md](docs/WORK_ORDER.md)

## 하지 않는 것

- 아이폰. iOS는 다른 앱을 막을 수 없어 만들지 않습니다.
- 화면 글, 메시지, 비밀번호, 계정을 읽는 일.
- 사용량 API. YouTube 전체 시간만 알 수 있어, 접근성으로 쇼츠 화면에 머문 시간만 잽니다.
- 치료·진단 같은 의료 효과 주장. "디지털 웰빙", "건강한 사용 습관 관리"를 돕는 앱입니다.
